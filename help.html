桌面日历 · 功能介绍

一款常驻桌面的透明日历工具，支持农历与节气显示、工作事件管理、重复事件、提醒、搜索与导入导出。全部数据保存在本机，无需联网。

主界面

  • 日期栏页面包含今天时显示“年月日 星期 农历日期”，否则显示“年月”。
  • 翻页顶部 ◀ ▶ 按钮向前/向后翻页。
  • 周号栏最左侧显示每行所属周在一年中的周号，跨月周自动扩展。
  • 日单元格左上角显示日期与农历/节气；双击进入编辑状态。

工作事件

  • 每条事件包含：工作内容、开始时间、结束时间（默认当天 23:59）、状态。
  • 状态自动推算：未开始 / 进行中 / 已完成 / 超期未完成。
  • 编辑状态下回车自动新增编号条目；“确认完成”切换光标所在条的完成状态。

重复事件

  • 支持每天/每周/每月/每年及自定义日、周、月、年重复。
  • 可设置重复限制：无限制 / 结束日期 / 重复次数。
  • 可为重复事件统一设置提醒时间；“删除任务”将删除全部派生事件。

提醒

  • 事件可设置提醒时间，提醒日期最多提前 3 天。
  • 支持当天内按 N 分钟 / N 小时重复提醒，并可限制最大次数。

总设置菜单

  • 隐藏日历隐藏窗口（不退出），再次运行程序即可显示。
  • 调整位置和大小进入虚线框模式，拖动边缘缩放、内部移动，✓ 保存 / ✕ 取消。
  • 切换色调在浅色/深色调之间切换。
  • 历史搜索按关键字搜索所有日单元格内容，双击结果跳转。
  • 导入/导出支持文本(txt)、Excel(xlsx)、CalendarTask数据库(db)。
  • 选择日期多级日历选择后跳转并进入编辑。
  • 设置日历 / 单元格 / 高级 三组设置，支持恢复默认。
